# AWS Solutions Architect Associate (SAA-C03) Study Links

This repository contains hands-on AWS practice. The resources below are useful
alongside the freeCodeCamp SAA-C03 course by Andrew Brown (ExamPro).

## Course

- [Andrew Brown / ExamPro SAA-C03 course on YouTube](https://www.youtube.com/watch?v=c3Cn4xYfxJY)
- [Official AWS SAA-C03 exam guide](https://docs.aws.amazon.com/aws-certification/latest/solutions-architect-associate-03.html)

## Community study notes

These are independently written SAA-C03 notes, not official course notes.

- [AWS SAA-C03 Study Notes](https://techikrish.github.io/aws-sa-notes/) — searchable notes arranged by service and exam domain.
- [Vikas's SAA-C03 notes](https://github.com/vikas9dev/AWS) — shorthand notes and Well-Architected Framework material.
- [Vicjor's SAA-C03 notes](https://github.com/vicjor/aws-saa-c03) — broad notes and a linked Notion study guide.
- [Asif Vora's SAA-C03 notes](https://github.com/asifvora/aws-solutions-architect-associate-notes) — useful core-service notes for IAM, EC2, S3, and networking.
- [SAA-C03 master cheatsheet](https://github.com/devesh-talreja/aws-saa-complete-cheatsheet) — concise comparison and revision material.

## Andrew Brown's own material

I could not find a public set of notes authored by Andrew Brown specifically
for the linked freeCodeCamp video. The official ExamPro SAA-C03 course includes
downloadable lecture slides and cheatsheets for enrolled learners:

- [ExamPro SAA-C03 course](https://www.exampro.co/saa-c03)
- [Official follow-along repository](https://github.com/ExamProCo/TheFreeAWSSolutionsArchitectAssociate)

Use community notes to reinforce the course, but verify time-sensitive details
against AWS documentation. Do not use exam dumps; focus on concepts and labs.
